Bibliothèque de sons et de rythmes

Des coups de batterie, des rythmes du monde et des neuf genres d'Harmonie, des sons de synthèse. Écoute, puis ajoute sur la piste choisie, au curseur rouge. Tout est fabriqué dans ta page, rien n'est téléchargé.

    Séquenceur à pas

    Allume des cases pour fabriquer un rythme : un clic pour un coup, deux pour un coup doux, trois pour effacer. Le motif suit le tempo du projet ; « Ajouter au projet » en fait un clip.

    Mes projets

    Chaque projet est gardé dans ce navigateur, avec ses sons, jusqu'à ce que tu le supprimes. Ouvre-en un autre sans perdre celui-ci. Pour garder un projet ailleurs ou le passer à un autre appareil, exporte-le dans un fichier.

        Jouer un instrument

        Joue avec un clavier MIDI, avec le clavier de l'ordinateur (rangée Q S D F G H J K L M, avec 2 3 5 6 7 pour les noires) ou avec les touches ci-dessous. « Enregistrer les notes » lance la lecture des autres pistes et garde ce que tu joues : à l'arrêt, les notes sont rendues avec l'instrument en un clip sur la piste choisie.

        Aucun clavier MIDI branché : utilise le clavier de l'ordinateur ou les touches de l'écran.

        Composer par blocs

        Notes
        100 %

        Clique dans la grille pour poser une note. Glisse dans le vide pour en choisir plusieurs (Maj ou Ctrl pour en ajouter). Glisse les notes choisies pour les déplacer, tire le bord droit pour les allonger, le bord gauche pour les raccourcir. Clique la règle pour placer le repère (où l'on colle et d'où l'on écoute). Les barres du bas règlent la vitesse de chaque note. Flèches : un pas ; Maj + haut ou bas : une octave ; Ctrl + C, X, V, D, A : copier, couper, coller, dupliquer, tout choisir.

        Glisse une note sur la portée : tu l'entends pendant que tu la déplaces. Ou touche une note de la palette, puis touche la portée. Glisse une note posée pour la changer de place, appuie sur Suppr pour l'enlever.

        Écrire en texte (comme dans LilyPond)

        Écris la musique en texte : la partition se dessine et les notes du clip suivent. Clique une note de la partition pour retrouver son texte. Quand tu changes le texte, les notes du clip deviennent exactement celles de la partition.

        Aide-mémoire LilyPond
        • Notes : c d e f g a b (ou do ré mi fa sol la si). Dièse : cis, bémol : ees, bes. Octave plus haute : c', plus basse : c,. Avec \relative c' { ... }, chaque note se place à l'octave la plus proche de la précédente.
        • Durées : c1 ronde, c2 blanche, c4 noire, c8 croche, c16 double croche ; point : c4. ; une durée écrite vaut pour les notes suivantes.
        • Silence r4 ; accord <c e g>4 ; prolongation c4~ c4 ; liaison c( d e).
        • Nuances c4\p \mf \f ; soufflets c\< d e\! ; articulations c-. staccato, c-> accent, c-- tenuto.
        • Réglages \clef bass \key d \major \time 3/4 \tempo 4 = 100 \partial 4 (anacrouse).
        • Triolet \tuplet 3/2 { c8 d e } ; reprise \repeat volta 2 { ... }.
        • Deux portées (piano) : \new PianoStaff << \new Staff { ... } \new Staff { \clef bass ... } >>. Variables : melodie = \relative c'' { ... } puis \melodie.
        • Commentaire : % jusqu'à la fin de la ligne.
        • SONORA comprend le cœur de LilyPond, pas tout : pas de voix superposées, de paroles, de notes d'agrément ni d'alternatives de reprise. Chaque refus s'explique dans le message d'erreur.
