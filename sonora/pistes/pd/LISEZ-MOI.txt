Compilateur Pure Data pour le navigateur : WebPd 1.0.0-alpha.14 (https://github.com/sebpiq/WebPd), licence LGPL 3, texte dans LICENCE-webpd.txt.
Le fichier webpd.js est fabriqué par outils/pd/construire.sh à partir du paquet npm, sans modification du code de WebPd (regroupé en un seul fichier).
WebPd est en version alpha : il ne gère qu'une partie des objets de Pure Data (osc~, phasor~, noise~, lop~, hip~, vcf~, line~, delwrite~, metro, mtof, expr...).
Il est chargé seulement quand on utilise Pure Data dans SONORA Pistes (panneau « Faust, Csound et Pure Data »).
